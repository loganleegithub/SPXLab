## 5. 定价：我们真正要检验的东西

对于同到期、等翼宽、1:-2:1 的看涨借记蝶式，中心为 K、单边翼宽为 w，到期结算指数为 S，组合到期价值（指数点）为：

`g(S) = max(w - abs(S - K), 0)`

若实际组合借记为 d 点、每组直接费用为 f 美元，则：

`净损益 = 100 × [g(S) - d] - f`

定义含直接费用成本 `c = d + f/100`，且 0 < c < w 时：最大损失为 100c 美元，最大净利润为 100(w-c) 美元，两个结算盈亏平衡点为 `K ± (w-c)`。固定订阅/运行成本另计。SPX 乘数为 100，欧式行权、现金结算；必须区分同日 PM 的 SPXW 与其他结算系列。[Cboe 产品说明](https://www.cboe.com/tradable-products/sp-500/spx-options)、[合约规格](https://www.cboe.com/tradable-products/sp-500/spx-options/spx-specifications)

**价格是否便宜，要相对未来兑付分布判断。** 若有在决策前形成且经过校准的完整条件分布，才可比较 `100 × (E[g(S)] - d) - f`。`d < w` 只表明成本低于最大兑付，不证明正期望；“假定现价不动”的结算价值也不是无风险套利。

现有图像只有点预测、部分概率带和路径触碰概率，不能据此唯一还原 E[g]。6000 条模拟路径的散点图不等于取得了带权、可复核的完整样本。以后自行拟合分布必须标为自己的模型，并单独校准，不能冒称作者输出。

静态例子：25 点翼宽、含费成本 6.25 点时，最大损失 $625，最大净利润 $1875，结算须距中心小于 18.75 点才有正净利润；若含费成本改为 9.25 点，则盈利距离缩至 15.75 点。后一例是假设费用的算例，不是对作者实际收费的推断。**同样预测误差，价格不同就可能改变盈利结果。**

### B. 筛选和相邻中心价格是否有增量——新增草案，未冻结

建议先保持 V0 的固定时刻、25 点翼宽和持有结算，限制变量数量；作者的动态择时、55 点宽度和提前退出留待独立版本。研究层比较以下五个反事实账本，不把它们当成同时下五笔真实单：

| 账本 | 中心选择 | 筛选 | 回答的问题 |
|---|---|---|---|
| S | 最近挂牌现价中心 | V0 数据/成本资格 | 现价基准 |
| F | 最近挂牌预测中位数中心 | V0 数据/成本资格 | 预测中心的增量 |
| FG | 同 F | 另加 G0 | 仅增加筛选的效果 |
| FP | P0 价格选择 | V0 数据/成本资格 | 仅改变相邻中心选择的效果 |
| FGP | P0 价格选择 | 另加 G0 | 二者组合及交互作用 |

为形成可讨论的起点，提出以下**我们自己的简化规则**，不归于作者：

- **G0 候选定义**：只采用截止前明确、校验通过且无未裁定冲突的来源 `LONG GAMMA` 标签；明确 SHORT 则拒绝，未知/冲突则记 UNKNOWN。它只是一个最简单的环境代理，**不等于作者完整 quiet gate**。不根据 spot 相对 Flip 的位置擅自重算符号。VRP、VIX9D、日内已实现波动先记录为诊断特征，定义未明确前不设置伪精确阈值。
- **P0 候选定义**：比较 F 中心及相邻上下各 5 点三个中心（仅实际挂牌且两翼存在时）；保持 w=25。用同一冻结/评估事件上的合格自然合成买价加估计直接费用，选择成本最低且满足同一上限者；成本相同先选离中位数近者，再取较低中心。后续延迟与成交资格重新检查，不追着后来报价重新挑中心。任一规定候选缺必要报价时，P0 标资料不足，不能静默缩小集合后宣布“最便宜”。候选三中心及首个评估时点还需在 M0 契约中定清。
- P0 仅检验有限范围内“价格取舍”是否改善净结果；选择更便宜的偏离中心也可能降低兑付。**不把最低价格命名为最优价值或正 EV。**
- 每账本仍至多一组。主指标保留 USD/全部计划日，并比较同日差值；不同交易频率的每笔胜率不代替主指标。另报告每单位最大风险、成本和参与率，避免宽度或频率改变造成误导。
- P0 需要更多候选报价，可能降低可用率或改变首个合格评估时点；全部计划日差值因此同时包含选择规则和数据要求的影响。另预先规定“同一时刻所有候选均合格”的配对诊断，不能把不同观察条件造成的差异全说成选价优势。具体同步评估语义在 M0 定清。
- 所有原始候选与拒绝原因均保留；诊断期与正式样本分开。正式期冻结候选集合、G0/P0、费用、时间与缺失规则，不能根据当天结果择优选一条曲线。

用户随后已明确确认：**五个完整影子账本首轮一并交付**（U08），包括费用、结算和回放。M0 要定好五账本契约，M1 为有限候选采集，M2/M3 验证所有账本。G0/P0 的具体参数和实施授权仍未冻结，不能把这次范围确认当作准许开工。

### C. 完整 quiet 与价值模型——需要新证据

若 G0/P0 结果不理想，不能说作者真实策略被证伪；若理想，也不能说复现了作者。要进一步研究真正的收敛筛选与 EV，需确定：

1. 对应决策时刻到 PM 结算的目标事件；为收敛定义可评分的未来结果，而不是用当天事后“看起来横盘”贴标签。
2. 可得的事前特征及各自期限：VIX/VIX9D、已实现波动、综合 GEX/墙、盘中区间。作者 07-23 回复 Gamma 为“综合”，不能假定其仅由 0DTE 生成。[原回复](https://x.com/Balder13946731/status/2080325332125847802)
3. 单一低复杂度基准模型、时间顺序样本外验证、概率校准和相对市场价格的费后比较；阈值由调试证据形成并预注册。
4. 作者未来若提供明确规则或订单流，作为新来源/新版本另行审查，不能与当前人工重建混成一条收益记录。
