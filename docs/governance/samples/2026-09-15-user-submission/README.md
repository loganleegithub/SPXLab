## 3. 配文中需要降为待验证假设的推论

1. **中位数不等于最可能的单点。** 中位数描述分布的中间位置；众数描述峰值位置。只有额外分布条件成立时二者才可能相同，图上没有足够证据作此替换。[NIST：位置统计量](https://www.itl.nist.gov/div898/handbook/eda/section3/eda351.htm)
2. **触碰 7600 不等于收在 7600 或全天停留附近。** 94% 若是路径事件的模型概率，终值仍可落到很远处。“全天磁吸”“最后防线”是额外叙事，不能当作图上已证明的概率含义。
3. **负 Gamma 机制是有条件的。** 净负 Gamma 对冲可能顺势放大上涨和下跌；影响还取决于净敞口大小。大成交量本身不足以确定做市商净头寸，也不能据此确认今天必然跌破加速或收复某点必然改变全市场对冲。[Cboe：SPX 0DTE 对冲与净头寸](https://www.cboe.com/insights/posts/volatility-insights-evaluating-the-market-impact-of-spx-0-dte-options)
4. **50% 是模型声明，实际覆盖率要靠事前样本检验。** 不能由图例直接得出实测“恰有一半交易日收在外面”，也不能把收盘区间解释成全天价格都在区间内。区间宽度 58 点与 ±81 的尺度关系需要模型定义；不强行套正态分布证明一致或矛盾。
5. **高 VRP 和 6,000 次模拟均不能证明扣费收益。** 本样本没有完整终值分布、当时可成交报价或费用信息，无法据此输出蝶式的期望收益或胜率。

以上不等于判定原模型无效；它们明确了哪些量可以记录，哪些主张需要更多证据。
