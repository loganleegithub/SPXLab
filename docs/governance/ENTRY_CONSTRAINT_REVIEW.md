## 3. 哪些门槛应如何处理

| 本系统门槛 | 复核判断 | 下一版处理建议 |
|---|---|---|
| 25点翼宽、含费成本≤6.25 | 固定25%成本/翼宽，等价于最大净利润/最大损失至少3倍；并非作者公开规则 | 保留为基线档，把成本比例作为独立研究参数；暂不因作者赢单直接改为9点 |
| 固定时点、15秒总窗口 | 有利于配对基线；用来代表作者全天是否有机会则明显不足 | 保留固定基线，另定义可复核的候选时段或环境触发规则；不能事后挑最好时刻 |
| 意图寿命3秒，其中先等1秒 | 只留下约2秒可观察成交资格；今日证据显示该限制有实质影响 | **优先测试10秒寿命，继续受总窗口和原数据质量约束** |
| 必要侧确认≤1秒、跨腿≤1秒、数量1/2/1 | 保守观察规则；没有作者依据，也没有覆盖所有组合成交机制 | 优先增加观察等待和确认能力；任何时效参数更改都单独留档验证 |
| 三候选必须同时合格，首个合格时刻只选一次 | 为相邻中心比较提供一致口径，但额外降低可用率；不等于作者动态优化 | 将候选数据缺口和经济拒绝分开统计，保留全部候选，避免隐性缩小集合 |
| LONG-only G0 | 与完整quiet筛选有距离，可能遗漏或误收；目前不足以断言净效果更好或更差 | 作为代理基线保留；作者参与意向另记，不把负Gamma日直接全部放行 |

因此，今日 F 的成本拒绝不可能仅靠把自然价替换成中间价解释掉。F 的7.0595相当于25点翼宽的28.238%，最大净利润/最大损失约2.54倍；被拒绝的直接原因是我们要求至少3倍峰值回报比。峰值回报比不是期望收益或胜率。

Cboe组合订单按净价及腿比例处理，并提供组合订单簿和竞价机制。由此可以推断，逐腿自然买价和顶层数量检查不是对全部真实组合成交机会的穷尽描述。但它们仍是本轮可审计的保守假设，不能无证据改用中间价记成交。[当前净价说明](https://www.cboe.com/document/tech-spec/content/technical-specifications/cboe-titanium-u.s.-options-complex-book-process/complex-order-basics/net-price)、[官方机制手册，2024版](https://cdn.cboe.com/resources/membership/US-Options-Complex-Book-Process-pdf.pdf)
