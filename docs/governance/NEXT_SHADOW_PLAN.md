# 下一轮影子验证方案

版本 0.1 · 2026-09-16（北京时间） · 状态：IN_REVIEW，尚未预注册、尚未启动。

依据：[9 月 15 日系统与来源复盘](../2026-09-15-RETROSPECTIVE.md)、U07/U08 五账本范围、U09 工程授权、U10–U12 当日修复与观察。维护：当前任务。人类确认的是项目范围；以下新的策略语义、跨日运行和研究参数仍是建议，不冒称已批准。

## 1. 目标与不变的对照

回答三个不同问题：

1. 能否在决策前取得并验证来源，连续记录有质量标记的候选？
2. 相同信息时点，预测是否优于现价基线；筛选是否改变费后收益，而不仅是命中率？
3. 给定同一预测，价值定价是否优于最近中心及最低成本选价？

S/F/FG/FP/FGP 五账本继续保留。现有 G0（LONG-only）、P0（邻近中心最低成本）明确标为本地基线；新规则使用新版本和独立结果。旧运行、缺失和无交易日均保留。数据采集和模型分析保持只读，下一交易日的运行时段需另行确定。

## 2. 首批工程交付：先让结果可解释

| 工作项 | 具体交付 | 完成证据 |
|---|---|---|
| E1 来源档案 | 产品 ID、预测 ID、版本、目标日期/时点、发布/首次取得/校验时间、原文图片哈希、作者参与标签及其时间 | 正常、迟到、目标冲突、改版、第二预测缺失案例可重放；未来信息不会进入旧决策 |
| E2 连续候选观察 | 预定合约集合及动态扩展规则，全部候选的价格、数量、年龄、同期比较；记录真实覆盖范围 | 能回答未入场由价格、筛选、来源还是行情缺失造成；缺少的合约不被算作合格或无机会 |
| E3 执行语义 | 区分含费风险预算、净借记限价、意图寿命、总窗口、观察延迟；终止原因与所有独立质量缺口 | 报价涨至原限价上方但仍低于预算、意图过期、跨窗口、数量不足等用例与契约一致 |
| E4 运行恢复 | 从启动就包含只读监督，断线代次失效、受控重连、人工登录需求，恢复是否可再入场显式配置 | 故障注入与读市场恢复证据；默认恢复不产生新的入场窗口，不跨账户权限 |
| E5 统一收尾 | 主组/控制组统一结算、重复执行不重复记账、结算修订追加版本、最终回放证据复用 | 正式值未发布、取得、修订、重复调用和中途退出均有明确状态 |
| E6 日报与通知 | 单一紧凑当前状态、独立历史日志；心跳增量检查、变更才通知 | 盘中告警/恢复、正式结算、完成通知各有去重键；完成后不会自动重启 |
| E7 数据保管 | 本地不可变清单、容量估计、恢复演练；确定长期留存及备份位置 | 文件哈希与权限核对；外部备份/上传在目的地与范围明确后进行 |

来源先沿用已授权网页/图片和必要人工校验。模型可提交候选提取结果，但不能改目标日期、研究规则或决策状态。持续获取频率由网页稳定性和发布时间证据制定；没有已建成 API 或邮件管道的假设。

报价应同时保存原始价格时间和确认时间；对不合格组合记录全部适用原因，而不仅是函数最先返回的一个原因。研究日志和运行通知分开，避免大量重复提示掩盖真正故障。

## 3. 入场设计草案：分清基线与动态研究

### 3.1 固定五账本基线

建议继续以纽约 10:05 为固定对照点，原 25 点翼宽、6.25 点含费预算、G0/P0 等保留。来源必须在截止前完成验证；否则来源依赖账本记缺失，S 仍按自身数据条件执行。基线只用于稳定测量，不能解释成完整复制作者。

今天的数据不补回这个时点。交易日历明确纽约时区、夏令时和半日市；不直接按固定北京时间运行。

### 3.2 动态候选先做观察，随后再定义入场

建议下一轮连续记录常规交易时段的候选状态，给出覆盖区间；**先不把每次合格都记为新交易**。由采集成本和盘口订阅上限决定有限、预声明的候选集合，不能称其为全市场。

动态入场研究另冻结总观察区间、候选生成规则、首次触发条件、作者资料更新处理、最多一次入场、固定限价/撤销规则及截止时刻。建议采用“限定窗口内首次满足条件”，而不是事后选择最便宜或收益最高时点。15 秒和更长窗口的比较必须使用同一事前候选定义；窗口长度不从今天的最佳结果反推。

将“第一份合格报价超预算即结束”与“允许在预定窗口继续等价格”单独比较；这改变交易语义，不能包装为无影响的 bug 修复。若候选中心随时间更新，须事前定义何时锁定及更新次数；不能无界择优。

## 4. 实验顺序与停止条件

| 阶段 | 研究内容 | 暂时保持不变 | 验收与后续条件 |
|---|---|---|---|
| A：可观测性 | E1–E6，完整交易日档案、来源时间和故障处理 | 不以更多成交作为工程成功指标 | 建议先积累 5 个运行日；报告预期/实际采集时段和缺口、每日完成结算回放；5 日仅是工程检查点 |
| B1：等待 | 同一合格意图，3 秒与 10 秒，同流对照 | 价格预算、质量、数量、延迟、翼宽、预测版本 | 必须实际出现意图和不同等待结果；没有意图就记未识别，不宣称两种寿命等效 |
| B2：窗口与可用性 | 原首次合格即决定，比较预定窗口内继续观察；F/FP 加同事件同期诊断 | 先不一起调整价格、quiet 或翼宽 | 记录触发覆盖、源缺失、候选缺失、等待时间及每日独立样本；成交分支仍只是影子假设 |
| C1：成本敏感性 | 预先规定 25%/30%/40% 成本/翼宽诊断档位 | 同一来源、时段、候选与成交模型 | 所有档位一并报告；探索结果只用于下一批冻结，不在本批挑最优档作为策略收益 |
| C2：quiet 与定价 | G0/P0 基线，对照少量自定义可测特征与分布价值规则 | 不同时扩张翼宽、期限和无限参数网格 | 训练/验证按交易日分离，保留跳过日；无足够分布证据则 EV=UNKNOWN，不产生伪确定的价值排名 |

阶段不是承诺几天就能证明盈利。A 完成后才确定正式效果实验的最低经济收益和统计精度；样本量根据日级方差、效应大小和置信区间制定。20 或 30 天可以做描述性检查，不能自动成为盈利验收阈值。

如果来源长期晚于 10:05、第二预测不可取得、盘口订阅不覆盖候选或持续缺失，则先记录覆盖问题并重设计下一批实验。缺失不填零、不挑可观测的好日子单独宣布胜率。

## 5. 筛选与定价的可实现边界

### quiet

- 作者参与/跳过是有时间戳的外部标签，不等于可复制的判定算法。未表态、晚取得、含糊表态分别编码。
- 自定义特征可从剩余时段实现波动、实际期权隐含定价、预测区域与现价距离等开始；须明确回看窗口、单位、可用时间和校准方式。
- VRP 的计算期限和定义必须明确；不能把图上一个 VRP 数字直接当作固定买入条件。LONG/SHORT 只是可保留的粗代理。
- 不使用收盘波动或当天结果来给当天“安静”打事前标签。全天与子时段预测分别验证。

### 价值定价

- P0 继续保留作为最低成本基线；“便宜”并不一定代表概率加权兑付足够高。
- 需要完整、可校准的条件分布，或明确标记为自己构建的分布假设。仅有中位数与 50% 区间不能唯一恢复作者密度。
- 比较美元预期净收益、最大损失、费用敏感性与预测误差，而不只最大化 ROC。真实世界概率与市场风险中性定价不混用。
- 优先同一 0DTE、相同翼宽和候选集合。作者 1–10 DTE 示意热图不能作为直接扩期限的实证依据。
- 组合订单簿净价、限价、排队与实际执行另立契约；没有已授权或已验证的券商模拟委托。

## 6. 每日报告的验收内容

1. **来源：** 发布、取得、校验、修订、目标时点；按产品区分；作者参与标签当时是否可见。
2. **行情：** 实际覆盖与缺口、行情类型、所需侧/对侧确认年龄、跨腿差、数量、候选全集覆盖、重连代次。
3. **决策：** 第一份合格报价、选择理由、候选同期对比、价格预算与限价、意图/等待/成交假设或拒绝的完整链。
4. **预测：** 中位数误差、区间覆盖与宽度；相同决策时点可用现价对照。预测发布日期的现价若不可得则记缺失。
5. **经济性：** 已确认影子假设分支的直接费后结果、固定成本口径、最大损失、回撤、无交易日、未知结果数量及其影响；不将未知日排除后冒称全样本净收益。
6. **完整性：** 计划/代码/来源/费用/成交模型哈希、正式结算、所有主控制结果和精确回放、研究偏差与版本。

对于零确认成交的日子，日报的成功标准是准确解释和保留证据；不能为了产出收益数字降低数据门槛。

现有五账本范围、独立蝶式方向、只读和无真实仓位已经确认，不重复询问。尚需定稿的是：

| 事项 | 建议 | 影响 |
|---|---|---|
| R1 下一批实验是否增加动态等待分支 | 固定五账本基线保留，先加全天候选观察，再冻结有限动态窗口 | 改变观察/交易时机的研究含义，需要独立版本；不是简单把 15 秒改成全天 |
| R2 持续运行时段与人工责任 | 下一指定交易日先完成 E1–E6 后运行；开市前校验 Gateway 和来源，必要时由用户登录，收尾自动停止 | 需要确定交易日与日历；本日收盘授权不自动变成无限期夜间运营 |

成本比例、翼宽、EV 阈值、正式样本量暂不同时拍板；先用观察形成可比较的方案，再预注册。研究未定稿不妨碍已授权的普通工程修复，但本次交付仅为复盘和方案，没有启动实现或下一交易日。
