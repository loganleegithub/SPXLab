# 独立 SPX 蝶式研究宪法

版本 0.2 · 2026-09-16 · 状态：核心原则与方向边界 ACCEPTED；具体操作化条款和验收方法仍为设计草案。

触发：用户要求判断作者“无偏估计的收益”是否构成策略根本原则，随后明确选择“分布价值优先：允许有证据的中心偏移，方向贡献单独归因”。理论与证据见[收敛门与无偏研究](../research/CONVERGENCE_GATE_AND_UNBIASED_EDGE.md)。本原则不改变既有五账本、不撤销已授权工程工作，不赋予券商委托或下一交易日自动运行权限。

## 核心原则

**独立蝶式以可验证的条件终值分布相对可执行价格的费后优势为依据。主观方向愿望不得替代概率估计；预测、筛选、方向位移、定价与执行的贡献分别接受样本外检验。**

人类已确认的简明表述为：**分布价值优先，允许有证据的中心偏移，方向贡献单独归因。** 上述完整句是该选择的研究解释；不保证盈利，也不认证作者秘密算法。均值无偏、中位数校准、Delta中性和无选择偏差分别检验，不合并成一个词。

## 核心原则的操作化草案

以下七项是助手提出的实现与验收建议，不把对核心原则的确认扩大成全部数值参数或技术方法已批准。

| 条款 | 要求 | 如何检查 |
|---|---|---|
| C1 收益理由 | 入场理由必须落到条件兑付、可执行成本及估计不确定性；命中率和低借记不能单独放行 | 每个意图保存分布/模型版本、成本、EV范围；无分布的基线明确为对照，不伪称价值策略 |
| C2 条件可信 | 收敛以当前剩余期限的终值约束为主要研究对象，区分回归强度、噪声、锚点变化及尾部 | 同期限、同时点对照；迟到、不稳定或缺失输出UNKNOWN，不靠事后图形确认 |
| C3 方向诚实 | 不先决定涨跌再找理由；允许优化中心，但必须披露方向敞口及优势归因 | 比较现价/远期中心、移除分布方向位移的模型消融、持仓Delta及中心距离；若收益主要依赖方向，单列命名和讨论 |
| C4 成本约束 | 收敛仍须通过独立价格门；实际盘口、直接费用、滑点假设和固定成本可追溯 | 预算与净借记限价分开；使用同一期限；不以理论中间价充成交，不以已知结算倒推最优结构 |
| C5 研究无偏 | 门、窗口、候选和版本事前冻结；全部计划日、尝试、跳过和缺失保留 | 日级样本外检验；不反复使用验证集调参；最大化多个候选时报告选择乐观偏差 |
| C6 风险有界 | 每一结构先明确最大损失、共同风险、失稳及运营失效处理；无偏不豁免尾部 | 规模和权限按阶段另批；不因模型自信加码或追损；不自动增加对冲订单 |
| C7 可被证伪 | 若集中度、费后价值或相对基准的增量消失，允许停止、简化或改名 | 门开/关、现价/预测、简单/复杂模型对照；事前记录失败判据与模型更新流程 |

## 不直接写成硬规则的四句话

- “永远K=spot”：几何中心相同不等于Delta为零，也可能妨碍有证据的价值选择。
- “所有日子预测平均误差必须等于零”：均值和中位数不同，短样本也不能据此验收交易优势。
- “LONG Gamma必做、SHORT必不做”：目前只是G0代理基线，不是已证实的普遍条件。
- “准确率越高越值得交易”：价格会反映确定性，准确与费后盈利分别检验。

## 已确认的取舍

**用户已选择“分布价值优先，方向贡献单列”**，允许研究发现混合收益来源。中心可以偏离spot，但理由、估计误差和方向贡献必须可检查。

未选择的更严格选项是“基础策略必须在移除方向位移后仍有优势，方向模块独立排除”。不把它暗中加入验收。移除方向位移仍可作为归因诊断，不自动成为否决全部策略的门。

严格持仓Delta上限及是否动态对冲是另一项执行/资金决定，不由本原则自动引入。G0/P0历史基线继续原样保留；已确认原则约束新价值研究版本的设计与解释，不回写历史。
