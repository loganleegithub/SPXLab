# 首轮实施基线

版本 0.1 · 2026-09-15 · IMPLEMENTING。用户明确“尽快开始施工，验证今天的交易”，已授权五账本影子系统。不是券商委托授权。

## 本轮工程决定

- Python 3.12，独立虚拟环境，ib_async 2.1.0（与历史已验证连接版本一致，项目官方文档仍列2.1.0）。标准库 SQLite WAL/JSON 为原始记录，Parquet 规划为可重建导出，当前尚未实现。
- 预测先作有原文/图像哈希的结构化录入，记录实际审查者；模型用于开发和审查，不调用运行时模型 API。自动提取是后续增强，不阻塞今日诊断。
- 原交接保持原位，新建代码与运行档案，不复制旧虚拟环境和临时探针。
- S/F/FG/FP/FGP 各至多一组，反事实账本不相互消耗流动性。25点翼宽、同日 SPXW PM calls、含估计直接费用上限6.25点；意图后1秒开始检查，3秒及总窗口15秒取较早截止。持有结算。这些是调试基线，非正式效果验证预注册。
- G0：明确 LONG 通过，SHORT 拒绝，未知/未裁定冲突隔离；不代表作者完整quiet gate。
- P0：F中心及上下各5点三个实际挂牌候选。全部候选必要报价在同一事件合格后，按含费成本、离中位数距离、较低中心排序，仅选择一次。延迟后不重新择优；缺候选数据不偷偷缩小集合。
- 现价/中位数取最近5点网格中心，等距取低；实际合约必须核验，未挂牌/未预热不补选、不延长窗口。盘口各价格年龄≤2秒、各数量≤1秒、必要价格跨腿时间差≤1秒；必须实时，连接世代改变即失效；SPX现价年龄≤2秒。
- natural买价=两翼ask-2×中心bid；尺寸至少1/2/1，三腿盘口不倒挂。费用采用明确来源和版本的估计；实际费制未知不得冒称实收费。固定开支单列。组合成交始终为假设，不声称保证成交。
- UTC接收时间、单调时钟及SQLite全局追加序号一起保存。计时器进入日志；截止先于同刻新行情，回放遵循持久化序号。每次连接独立世代，断线/类型变化不沿用旧数据。
