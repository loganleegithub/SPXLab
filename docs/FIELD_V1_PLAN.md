## 采用的最小实现

1. 在现有 V2 运行链加入独立 `FIELD_PAPER_V1`，复用 Collector、ResearchJournal、报价校验、单次意图、固定限价、冻结回放及正式结算。LOOKAHEAD 与 FIRST_POSITIVE 共用一个 FIELD 采集流。原 OBSERVE/DV1 与已冻结运行不改语义。
2. 增加局部模型和一步时机两个计算模块。有效连续分钟增量至少20个、最多60个；Pin 回归 κ 向零收缩，保留负号，正值上限 log(2)/10；EWMA 平方增量半衰期20分钟。无有效 Pin 时自动使用 MARKET_ONLY。正回归时背景/锚定各半；各分支90%基础噪声、10%九倍方差。均为待检验假设。
3. 每30秒重新以本次合格SPX条件化；每分钟更新参数。解析正态混合保留完整尾部。120秒一步继续价值使用相同混合过程和后验分支权重，Q再定价从当前合格腿价单独反解，固定当前执行摩擦。15节点与31节点比较，数值不稳定/价格不可识别时明确降级FIRST_POSITIVE。
4. 同日25点翼宽，单组，含费预算6.25点；点EV扣0.25点缓冲后为正才允许探索性候选。缺其他结构保留缺失行，允许选择已合格子集。固定初始净限价、1秒延迟、10秒寿命；每账本每天最多一次意图。
5. 复用现有 Python 运行器生成自动刷新的中文单页，以及追加的预测、决策、1/5分钟评分和120秒等待核验。正式结算后统一评分全部终值预测与两个账本。缺失保持未知；同日多个时点不当成独立交易日。
