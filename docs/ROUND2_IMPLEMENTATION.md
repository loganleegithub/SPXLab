## 工程实现与接口

核心新增模块为`contracts/calendar/forecast/dataset/distribution/valuation/quotes/policy/shadow/research/frozen/settlement/evaluation/diagnostics/observer/research_cli`。领域代码不持有Gateway；观察器复用封闭协议白名单，仅允许行情订阅/取消、合约详情、时间、行情类型和握手。旧CLI命令保持旧语义，新命令见[运行手册](ROUND2_RUNBOOK.md)。

结构固定宽25、数量1、预算6.25点、1秒延迟、10秒意图寿命；策略每个计划日最多一个意图。费用采用已声明的公开收费场景，实际账户费制未确认。自然腿价只支持影子假设，不证明真实组合成交。

原始事件及同次产生的估值/决策/意图在一个SQLite事务提交。失败的writer停止，禁止保存未提交状态；恢复回放完整已提交日志，重启另起epoch。输入seq、UTC、单调时钟、计划时点、处理时点及引用hash保留；同刻计时器先于新报价输入，迟到不回填。所需报价侧缺失、过期、撤回或数量不足保留全原因。到期前未完整观察不能记成确认未成交。

源快照包含源码、必要运维脚本、依赖锁、Python/平台、配置和日历版本；事件记录模型/来源/候选内容及hash，停止封条记录最后事件hash、计数和结果hash。回放在隔离Python进程中加载该快照，禁网络及写原件的防误用检查；它不是对恶意Python的安全沙箱。旧运行没有完整环境清单，旧回放只验证已有源码/结果，不补称异机重建通过。
