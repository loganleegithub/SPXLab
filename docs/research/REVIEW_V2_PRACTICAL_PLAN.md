## 4. 从实际交易看，真正需要算什么

一组同日SPXW PM等翼借记蝶式，持有至结算时，核心问题是：**这个中心附近的预期兑付，是否足以支付买入成本及误差余量。**

`b(S;K,w)=max(w-|S-K|,0)`，`c=净借记+直接费用/100`，`J=E[b]-c`。

还可以展示无量纲的 `E[b]/w` 与 `c/w`；前者是预期兑付占峰值的比例，**不是胜率**。仅说“区间窄”“价格横盘”“LONG Gamma”不能回答J是否为正。更集中时蝶式可能也更贵；安静市场可能没有价值，较宽分布下便宜结构也可能有价值。

现有6.25点预算是每组最多约625美元的含估算直接成本约束，25点翼宽限定兑付形状；二者都不是正期望证明。它们会排除一些更贵结构，也可能留下较远、较便宜的中心。当前应保留为已接受的比较基线，报告被排除的原因，不在看完结果后提高预算。

### 第2–3步的最小模型与报告

第一版按固定信息时点到PM结算建立同日误差 `e_i=结算_i-锚点_i`，每天一份同产品、当时可用的预测；先用原始点数残差（scale=1）作为明确的简单基线。跨波动环境外推是其已知限制，不先新增波动预测器。现价锚点和作者锚点各用自己的残差样本；没有同刻现价就不输出伪造的比较。

用共同终值样本对现有最多4个中心计算兑付。报告模型日数、样本日期范围、预期兑付、点EV、历史逐日兑付误差和对训练日的敏感性。若历史波动状态相差太大，先说明基线不适用；只有看到与实际报价相比有意义的系统误差，才增加一个可解释的尺度或特征。

误差评估按时间顺序逐日向前计算，次日预测只使用前日已成熟资料。留一日分析可看单个样本是否主导，但不能冒充因果样本外业绩。需要抽样区间时按整日共同重采样，使4个候选共享同次训练扰动；初期只作稳定性诊断，不包装成真实条件EV的保证下界。不能让每个候选分别挑最有利的模型。

**现有代码已经能输出点数。** 本次探针在EXPLORATORY元数据下得到16/21/24/19的兑付点估值，同时保留MODEL_NOT_READY、UNCERTAINTY_NOT_ELIGIBLE和selected=null。因此第3步主要是整理真实输入与改善展示，不必先实现STATISTICAL_INTERVAL类型。POINT_ONLY的lower=upper只是代码存储约定，界面必须显示“点估值”，不能写成零宽置信区间或保守价值。

单页报告应回答：信息截止/实际可用时刻；预测目标与来源；现价及候选；预期兑付和买价；最多可损失多少；距离盈亏平衡多远；当日动作状态的具体原因。展示不改变意图权限。正式DV1资格、研究成效证明和是否允许影子动作是三个不同决定。

对正式DV1，外部指出的资格断点确实存在。若之后继续沿用“最大价值下界”目标，必须实现并验证真正的不确定性适配，或使用有来源的概率约束；不能将经验分箱质量当已知真概率。也可以另行冻结一个明确探索性的点EV影子基线收集失败结果，但这是新研究规则，不能通过改状态标签冒充原DV1。**先不要为两条路线各搭一套通用运行框架。**

### 第4步前两个必须实际解决的接入细节

1. **模型落盘时钟。** ResearchEngine对非历史导入的DISTRIBUTION要求available_at恰好等于事件记录时刻。本次用晚1毫秒的交付复现拒绝。这是防回填契约，不能删掉；新intake应保留模型computed_at，并用实际事件接收/落盘时刻确定available_at。一个10:05才开始计算的模型不能用于10:05截止决策；要提前产出，或把新版本的固定评估时刻向后排定并同步训练时间桶。先固定一套时间安排，不做可配置调度平台，也不伪造零耗时。
2. **在途结构订阅。** 当前Observer只按最新候选refresh。离线调用真实refresh代码：假设已有K7600待定意图，现价中心移至7605，原7575/7600/7625三腿全部被取消。本日OBSERVE_ONLY不会有该意图，故不是已发生市场事故；但直接复用到影子运行会丢失成交观察。新驱动的订阅集合应保留“当前候选 + 未终止意图三腿”，TTL结束后释放，仍遵守现有上限。无需新增订阅管理服务。

这两项只有在启用真实价值影子时才是施工项，本次不为尚未开启的功能改动正在运行的观察器。

## 8. 验收止点

- 修复阶段：两个失败反例变绿、合法输入不退化即结束；不以测试总数作为目标。
- 数据阶段：首批真实样本及明确缺口能复跑；零样本不能写成模型已完成，也不因零样本转去建更复杂模型。
- 价值表阶段：至少一份真实报价记录与真实来源/训练依据相连；同一期限、实际时点、模型状态和费用假设醒目可见。只有点预测时不虚构置信区间。
- 影子阶段：模型实际交付、一次限价意图、完整后续观察与结算链被观察到。零意图仍可验证故障/调度等工程路径，但**不能据此声称价值影子业务已贯通**；必须说明未走到哪一步。
- 经济阶段：以所有计划日的实际规则结果、费用和未成交/未知为准。价格只有略微变化、删除一个训练日或换合理费用场景就使结论反转，应降低对信号的信任；不要先升级模型掩盖问题。

本次结论比“再收数据、再校准”多了一步：明确了现有数据不能怎么用、已经可以输出什么，以及接入真实影子时两处会实际卡住的代码。下一轮首先交付可使用的交易判断材料，工程围绕这份材料补齐。
