## 人工Pin最短流程

用户只需提供“本日收盘Pin=数值 + 原文”；Codex保存UTF-8原文，再代录：

```sh
.venv/bin/python -m spxlab.cli field-pin --run var/2026-09-16/field-v1-003 --pin '<人类明确给出的本日数值>' --text-file /absolute/path/to/today-original.txt
```

命令读取当前运行的纽约日期并拒绝跨日或收盘后输入。默认标签unspecified_point，原文明确为mode/median/mean时通过`--statistic-label`保留原标签。不是自动把原文解释成概率分布；区间、Gamma、touch和墙位仅保存在原文。

同一命令再次提交新数字即追加修订；撤回使用`--retract`替代`--pin`并提供撤回说明文件。原件、旧版本及旧决策保留。输出明确为QUEUED_NOT_YET_APPLIED，并显示目标日、实际接收时间、来源版本、下一评价和已用意图。运行器通常5秒内核验、记录FORECAST；页面显示已接收Pin及可用时点，最近一次模型使用的Pin另列，下一30秒评价使用新来源。启动预热期未满20增量时仍需等待模型数据。
